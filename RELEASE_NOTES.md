# BAM portable v3.4

Assets: `dist/bamp1-portable-v3.4.zip` and
`dist/bamp1-portable-v3.4.zip.sha256`.

Source: exact extracted distribution under `package/`. Repository README is
English/Japanese; installation instructions and Skill are principally English.
LICENSE is supplied at repository level alongside the original, unchanged ZIP.

The revised AM-T-027 fixture avoids unnecessary long evidence paths while
retaining corpus size and the P95 <= 2000 ms criterion. Failure reasons and
runner stderr are retained by the updated reporting path. The old ASUS failure's
root cause remains unconfirmed. The user reports successful operation of v3.4
on another PC; this does not certify automatic Skill use by every target LLM.

Installation downloads are the versioned ZIP and checksum assets, not GitHub's
automatic source archive. Personal memory, local evidence, receipts, scratchpads
and host configuration are not part of this release.
